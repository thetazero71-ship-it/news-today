## المرحلة 1 — وضع الصيانة الحقيقي 🔴

**المشكلة:** إعداد `site_status` غير مزروع في قاعدة البيانات أصلاً، ولا يوجد اعتراض في `index.php`، ولا صفحة صيانة. أي أن «وضع الصيانة» لا يعمل إطلاقاً.

### العمل
1. زرع `site_status` (`active` / `maintenance` / `private`) في مجموعة `general`.
2. زرع `maintenance_message` (نص يكتبه المالك من اللوحة).
3. اعتراض الطلبات العامة في `index.php` قبل `SecurityGuard` وقبل كاش الصفحات:
   - `site_status = maintenance` → **HTTP 503** + `Retry-After`.
   - استثناء: المدراء المسجّلون، `/admin/*`، `/login`، `/cron/*`، `/api/*`، والأصول الثابتة.
   - لا تُخزَّن صفحة الصيانة في الكاش.
4. إنشاء `views/errors/maintenance.php`: هوية الموقع، رسالة قابلة للتحرير، تحديث تلقائي كل 60 ثانية، بلا رابط دخول إدارة.
5. `SettingsController::save()`: إضافة `PageCache::flush()` حتى يُطبَّق القالب/الحالة فوراً.

### معيار القبول
- `tools/maintenance_test.php` ينجح بالكامل.
- طلب `/` أثناء الصيانة = 503، و`/admin` = 302 إلى الدخول.
- إعادة `site_status = active` تُرجع الموقع فوراً دون انتظار الكاش.

## المرحلة 2 — تحصين PWA 🔴

**المشكلة:** وسم الـ Manifest بلا `crossorigin="use-credentials"`، فيُرجع خادم الاستضافة صفحة HTML بدل JSON ويفشل التثبيت. و`sw.js` يعترض نطاقات خارجية بلا حماية.

### العمل
1. `views/partials/header.php`: إضافة `crossorigin="use-credentials"` لوسم Manifest.
2. `sw.js`: حصر الاعتراض في نفس الأصل، وإرجاع استجابة صالحة دائماً، وترقية الكاش إلى `AsabTech-v3`.
3. زر تثبيت دائم في الهيدر والفوتر + نافذة إرشاد (iOS/Android/Desktop).
4. `tools/pwa_test.php`.

### معيار القبول
- `manifest.json` يُقرأ كـ JSON دون كوكيز (اختبار حيّ).
- لا يوجد `respondWith(undefined)` في أي مسار.

## المرحلة 3 — تواريخ الخلاصات 🟠

### العمل
1. `site_dt()`: دعم الطوابع الرقمية (Unix) والقيم الفارغة بأمان.
2. `parseRssItem`: دعم `dc:date`, `atom:updated`, `atom:published`, `published`, `updated`, `date`.
3. تعافٍ ذاتي: عند غياب التاريخ استخدم `timestamp` أو `first_seen_at` من الكاش.
4. الإدارة: `dir="ltr"` + `font-monospace` لخانات التاريخ.
5. `tools/aggregator_pubdate_test.php`.

### معيار القبول
- لا تظهر `-` في تواريخ بطاقات المجمّع.
- الطوابع الرقمية تُعرض بتوقيت الموقع.
